# Customer Onboarding and Training

## Onboarding Phases

### Phase 1: Business Setup

- Confirm company name, address, phone, email, website, and GST details.
- Confirm tax rates.
- Confirm quotation validity period.
- Confirm payment terms.
- Confirm quotation terms and conditions.

### Phase 2: Catalog Setup

- Import or enter brands.
- Enter systems.
- Enter profiles with stock numbers, costs, weights, bar lengths, offsets, and angles.
- Map profiles to systems.
- Enter formulas.
- Enter glass types and costs.
- Enter hardware and rules.
- Validate sample products.

### Phase 3: User Setup

- Create admin users.
- Create sales users.
- Create production users.
- Create viewer users if needed.
- Verify access for each role.

### Phase 4: Pilot Workflow

- Run one complete sample project.
- Compare quote total with existing manual method.
- Compare generated cut list with workshop expectations.
- Adjust formulas and settings.
- Repeat until accepted.

## Training Plan

### Admin Training

- Company settings.
- Catalog maintenance.
- Formula changes.
- Project lock/unlock.
- Backup awareness.

### Sales Training

- Customer creation.
- Project creation.
- Measurement entry.
- Quotation generation.

### Production Training

- Production job creation.
- Production item generation.
- Diagnostics review.
- Optimization.
- Cutting list usage.
- Glass schedule usage.
- Hardware summary usage.
- Offcut tracking.

## Go-Live Checklist

- Production environment deployed.
- Admin account secured.
- Catalog approved.
- Company settings approved.
- Quotation PDF approved.
- Production output approved.
- Users trained.
- Backup tested.
- Support owner assigned.
- First live project selected.
